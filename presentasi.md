# Naskah Presentasi Project: MBG Insight (Web Design)

*Catatan: Pembagian tugas ini dirancang untuk 5 orang agar durasi bicara seimbang. Sesuaikan nama Pembicara 1-5 dengan nama anggota kelompok kalian.*

---

### 🗣️ Pembicara 1: Pembukaan & Latar Belakang Inspirasi
**"Halo semuanya, selamat [pagi/siang/sore]. Kami dari Kelompok [Nama Kelompok] akan mempresentasikan hasil akhir dari project Web Design kami yang bernama 'MBG Insight'."**

**"Website ini terinspirasi dari program nasional pemerintah yang sedang hangat diperbincangkan, yaitu Program Makan Bergizi Gratis (MBG). Kami melihat bahwa masyarakat butuh informasi yang ringkas, visual, dan mudah dipahami mengenai program ini. Oleh karena itu, kami membangun MBG Insight sebagai media edukasi interaktif untuk mengenalkan tujuan, sasaran, dan alur layanan dari program MBG."**

---

### 🗣️ Pembicara 2: Teknologi & Konsep Utama
**"Terima kasih. Selanjutnya, saya akan membahas tentang teknologi di balik website ini. Kami mengusung konsep 'Super Native'."**

**"Artinya, website ini murni dibangun menggunakan HTML5, CSS3, dan sedikit Vanilla JavaScript tanpa bergantung pada framework berat seperti Bootstrap atau Tailwind. Untuk saat ini, kami merancang tampilannya secara spesifik untuk layout Desktop agar informasinya dapat disajikan secara maksimal di layar lebar. Kami juga menggunakan sistem *CSS Variables* di `:root` untuk memastikan warna tema (Navy, Dark, dan Gold) tetap konsisten di seluruh halaman."**

---

### 🗣️ Pembicara 3: Section Atas & Interaktivitas
**"Masuk ke bagian struktur website. Di bagian paling atas, kami memiliki *Header* dan *Hero Section* (Halaman Utama)."**

**"Untuk navigasi menu di Header, kami tidak menggunakan JavaScript sama sekali untuk efek gulirannya. Kami sepenuhnya memanfaatkan fitur native CSS yaitu `scroll-behavior: smooth` agar perpindahan halamannya terasa halus."**

**"Sedangkan di Hero Section, kami menaruh background gambar yang memenuhi layar (full-width) dipadukan dengan efek animasi ketikan (Typewriter Effect) pada judul 'My Bini Gweh (MBG)'. Nah, khusus untuk animasi ketikan ini, kami menggunakan Vanilla JavaScript sederhana dengan memanfaatkan fungsi `setTimeout`."**

---

### 🗣️ Pembicara 4: Section Konten & FAQ Native
**"Di bawah Hero Section, terdapat beberapa section konten edukasi seperti *Tentang, Sasaran, Alur,* dan *Gizi*. Untuk menyusun kotak-kotak informasi tersebut agar sejajar dan rapi, kami menggunakan teknologi *CSS Grid*."**

**"Salah satu bagian yang paling menarik adalah section FAQ (Pertanyaan Umum). Biasanya, fitur buka-tutup teks (Accordion) membutuhkan JavaScript yang panjang. Namun, di website kami, fitur ini dibuat 100% menggunakan elemen native HTML yaitu tag `<details>` dan `<summary>`. Dengan begitu, kode kami menjadi jauh lebih bersih, ringan, dan efisien."**

---

### 🗣️ Pembicara 5: Kesimpulan & Penutup
**"Sebagai kesimpulan, project MBG Insight ini tidak hanya sekadar membuat tampilan web yang menarik, tetapi juga menjadi tempat kami belajar memaksimalkan potensi fitur native dari HTML dan CSS modern."**

**"Kami membuktikan bahwa interaktivitas dasar seperti *smooth scrolling* dan *accordion* bisa diatasi tanpa framework atau library eksternal. Hasilnya adalah sebuah website edukasi yang informatif, ringan, dan estetik."**
