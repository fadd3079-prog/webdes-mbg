# MBG Insight

Website informasi edukatif tentang Program Makan Bergizi Gratis (MBG). Dibuat sebagai proyek frontend native HTML, CSS, dan JavaScript untuk tugas mata kuliah web design.

## Fitur Website

- **Desktop-Only Layout**: Layout website difokuskan pada tampilan desktop
- **Smooth Scrolling**: Navigasi yang halus antar section menggunakan CSS native (`scroll-behavior: smooth`)
- **Interactive FAQ**: Accordion FAQ yang dapat dibuka/tutup menggunakan HTML native (`<details>` dan `<summary>`)

## Struktur File

```
webdes-mbg/
├── index.html          # File HTML utama
├── style.css           # File CSS untuk styling
├── script.js           # File JavaScript (dikosongkan untuk penambahan fitur ke depannya)
├── image/              # Folder gambar
│   ├── logombg.png     # Logo MBG
│   └── prabowo1.jpg    # Background image
├── docs/               # Dokumentasi konten
│   ├── content-mbg.md  # Konten lengkap website
│   └── prd.md          # Product Requirements Document
└── README.md           # File dokumentasi ini
```

## Cara Menjalankan

1. Buka file `index.html` di browser web
2. Atau gunakan live server jika menggunakan VS Code

## Teknologi yang Digunakan

- **HTML5**: Struktur website dan interaktivitas native (Accordion FAQ)
- **CSS3**: Styling, layout (Grid, Flexbox), dan Smooth Scrolling

## Konten Website

Website ini berisi informasi edukatif tentang:

1. **Program MBG**: Penjelasan tentang Program Makan Bergizi Gratis
2. **Sasaran Penerima**: Kelompok yang menjadi target program
3. **Alur Program**: Bagaimana program MBG berjalan
4. **SPPG**: Satuan Pelayanan Pemenuhan Gizi
5. **Manfaat Program**: Dampak positif program MBG
6. **Edukasi Gizi**: Komponen makanan bergizi
7. **FAQ**: Pertanyaan yang sering ditanyakan
