# PRD Sederhana - MBG Insight

## 1. Tujuan Project

Membuat website edukatif sederhana tentang Program Makan Bergizi Gratis.
Website harus mudah dibaca, memakai HTML/CSS/JavaScript native, dan tidak menggunakan framework.

## 2. Target Pengguna

- Siswa atau mahasiswa yang ingin melihat contoh project web basic.
- Pengunjung umum yang ingin memahami ringkasan MBG.
- Guru atau dosen yang mengecek struktur website sederhana.

## 3. Fitur Utama

- Header fixed dengan navigasi.
- Logo MBG di header sebelah kiri.
- Logo MBG sebagai favicon di tab browser.
- Hero section dengan background gambar.
- Section informasi tentang MBG.
- Tabel sasaran penerima manfaat.
- Card alur program dengan gambar.
- Card SPPG dengan gambar.
- Card manfaat dengan gambar.
- Galeri dokumentasi berisi kumpulan foto.
- Section edukasi gizi.
- Section standar gizi dengan tabel.
- FAQ interaktif sederhana.
- Footer dengan tombol Info Website.
- Tombol kembali ke atas fixed di kanan bawah berbentuk lingkaran.

## 4. Batasan Teknis

- Tidak memakai framework.
- Tidak memakai library tambahan.
- Tidak menambah JavaScript yang rumit.
- Tetap memakai HTML, CSS, dan JavaScript native.
- CSS harus mudah dipahami pemula.
- Layout cukup memakai flexbox sederhana.

## 6. Dokumentasi

Section dokumentasi dibuat sebagai galeri foto.
Tidak perlu deskripsi panjang di bagian dokumentasi.
Card dokumentasi cukup berisi gambar.

## 7. Kriteria Selesai

Project dianggap selesai jika:

- Website bisa dibuka dari `index.html`.
- Semua gambar yang dipakai tidak broken.
- Header, hero, section, card, dan footer tetap tampil rapi.
- Tombol kembali ke atas berfungsi.
- FAQ tetap bisa dibuka dan ditutup.
- Dokumentasi project di folder `docs` sudah sesuai dengan kondisi website terbaru.
